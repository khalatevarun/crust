# Skills

Vendored from two external skill collections:

- `.claude/skills`: `codebase-design`, `improve-codebase-architecture`, `domain-modeling` from [mattpocock/skills](https://github.com/mattpocock/skills), plus a subset of pstack (`architect`, `how`, `why`, `typescript-best-practices`, `principle-boundary-discipline`, `principle-model-the-domain`).
- `.cursor/skills`: the full [pstack](https://github.com/cursor/plugins/tree/main/pstack/skills) skillset from cursor/plugins.

`architect` depends on `how` and `why`; `improve-codebase-architecture` depends on `codebase-design`. Both pairs are kept together for that reason.
